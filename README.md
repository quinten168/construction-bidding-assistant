# csi-bid-intelligence

Data cleaning and bid-intelligence prep for CSI project bid data.

## Files

- `clean_data.py` rebuilds `CSI_data_combined.csv` from the 2024 and 2025 source CSV files.
- `CHANGELOG.md` documents each cleaning pass and audit-relevant row counts.
- `duplicate_project_review.csv` is generated by the cleaning script for possible duplicate/rebid review.

## Run

```bash
python clean_data.py
```

The script requires `pandas`.
